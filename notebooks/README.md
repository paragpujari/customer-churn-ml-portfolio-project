# Notebooks Directory

Place your Jupyter notebooks here for deeper EDA, feature engineering experiments, or model experimentation.

Suggested notebooks you can create:

1. `01_exploratory_data_analysis.ipynb` — distributions, correlations, target analysis, missing values
2. `02_feature_engineering.ipynb` — additional features, interactions
3. `03_model_experimentation.ipynb` — hyperparameter tuning, cross-validation, SHAP

The production training pipeline lives in `src/train_model.py` and is fully reproducible without notebooks.
